## backward
Using the p-value, it decides which features to use. If the p-value is over 0.05, that feature is not useful, so features are deleted iteratively.

## univarible selection
it uses chi²; you define how many features to use at the end. It assigns a score for the features; the feature is better as the score is higher.

## recursive elimination
It works by deleting features recursively, building the model with different combinations of the features
