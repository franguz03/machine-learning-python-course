## cohen's kappa

It is useful in problems with class imbalances, when the model classifies one category very well and not the other, it penalizes the errors that occurred for the unbalanced category.

## ROC (Receiver Operating Characteristic)

The ROC curve shows the performance of the model at different classification thresholds, allowing to see the balance between the true positive rate and the false positive rate. It is useful because it does not depend on a single threshold, as does the accuracy. The idea is that the values ​​approach 1
